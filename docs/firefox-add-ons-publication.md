# Firefox Add-ons publication plan

## Release decision

Library Seats SG uses one React/TypeScript application and one Manifest V3
manifest for Chrome and Firefox. There is no Firefox fork or second repository.
Version 1.4.0 is the first shared cross-browser release.

The first Mozilla Add-ons (AMO) submission targets Firefox Desktop 140 or
newer. Firefox for Android is deliberately excluded until the interface and NLB
workflow have been tested on Android.

## Compatibility review

The runtime uses content scripts, standard DOM and Fetch APIs, Web Crypto, and
`chrome.storage.local`. Firefox exposes the Chrome-compatible WebExtensions
namespace, so the application code does not need browser-specific branches.
There is no service worker, cookie permission, direct cookie access, remote
executable code, analytics, or developer server.

Firefox-specific manifest metadata supplies:

- permanent ID `library-seats-sg@teamcmcbot.github.io`;
- minimum Firefox version 140;
- Mozilla built-in data-consent declarations; and
- `incognito: "not_allowed"`.

Private browsing is disabled because Firefox extension-local storage is shared
between normal and private contexts. This avoids mixing private NLB activity
with normal-profile preferences. The shared manifest means this restriction is
also visible to Chrome, so both browsers require a focused regression test.

Firefox containers are not treated as simultaneous-account support. The
extension's profile model follows whichever NLB account owns the active browser
session and has not been validated as container-isolated storage.

## Build outputs

Run:

```bash
npm ci
npm run package
npm run package:firefox
npm run package:firefox-source
```

The outputs have separate purposes:

- `nlb-seat-helper.zip`: Chrome/GitHub release artifact;
- `nlb-seat-helper-firefox.zip`: built AMO submission; and
- `nlb-seat-helper-firefox-source.zip`: reviewer source with exact build
  instructions in `AMO_BUILD.md`.

The Firefox linter permits exactly three reviewed warnings and fails on any
new warning, notice, or error. Two warnings are generated by React DOM's
compiled implementation; project source does not use `innerHTML` or
`dangerouslySetInnerHTML`. The third warning concerns Android support for the
Firefox 140 data-consent key; this release is desktop-only.

## Required testing

Firefox receives the complete first-platform smoke test: temporary install,
signed-out state, sign-in/return, account refresh, profile preferences,
availability for today and a future date, seat-plan display, booking review,
cancellation review when an existing cancelable booking is available, route
changes, reload handling, and console/network errors.

For version 1.4.0, explicitly verify that:

- restored favourites trigger one initial availability check;
- changing library, area, or date triggers a check only when the resulting
  area has favourites;
- the seat plan is visible immediately on the first picker opening in Firefox;
- picker close and inline **Manage** → **Done** refresh only for a changed,
  non-empty final favourite set, while remove-and-restore preserves the
  existing timeline without a request;
- signed-out green cells remain view-only; and
- completed booking and cancellation status both show **Go to My Bookings**
  followed by an accessible × dismissal control.

Chrome receives a focused regression test of installation, signed-out and
signed-in rendering, storage restoration, availability, booking review, route
changes, the version 1.4.0 behaviors above, and confirmation that
private/incognito use is unavailable. Do not make or cancel a real booking
solely for testing.

Store screenshots must be checked in Firefox before submission. Existing
privacy-safe 1280×800 captures may be reused only if the Firefox rendering
matches; recapture any image with a browser-specific discrepancy.

## Publication boundary

Building and local testing do not publish anything. Uploading to AMO, accepting
final declarations, pushing tags, or creating releases changes remote state and
requires explicit authorization. AMO signs the approved package; the unsigned
Firefox ZIP is not a public install artifact.
