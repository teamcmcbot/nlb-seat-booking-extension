# Firefox Add-ons listing assets

Use the privacy-safe 1280×800 images in `assets/chrome-web-store/` as the
candidate AMO screenshot sequence. Before submission, load version 1.4.0 in
Firefox and verify that each represented state matches Firefox rendering.
Recapture any state with a browser-specific discrepancy and place the approved
Firefox capture in this directory.

The 64×64 AMO icon is `public/icons/icon-64.png`. Do not upload screenshots
containing an NLB account identifier, booking reference, personal browser UI,
or unreviewed seat-plan material.
