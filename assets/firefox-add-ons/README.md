# Firefox Add-ons listing assets

Prepare clean Firefox-native captures in this directory for the AMO listing.
Use the same feature sequence as the privacy-safe images under
`assets/chrome-web-store/`, but do not reuse Chrome-native date pickers or
caption-heavy composites when Firefox renders the state differently. Mozilla's
listing guidance recommends explaining annotations in listing text rather than
baking explanatory copy into screenshots.

Before submission, load version 1.4.1 in Firefox and verify each represented
state, including the native date picker, compact library/area/date summary,
fixed post-favourites region, Legend popover, and booking-mode help popover.
Keep each approved Firefox capture in this directory and reference its purpose
in the listing description.

The 64×64 AMO icon is `public/icons/icon-64.png`. Do not upload screenshots
containing an NLB account identifier, booking reference, personal browser UI,
or unreviewed seat-plan material.
