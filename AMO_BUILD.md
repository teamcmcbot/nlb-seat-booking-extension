# Firefox reviewer build instructions

This source archive rebuilds the exact Firefox submission package for Library
Seats SG - for NLB. It contains no account captures, credentials, cookies,
booking references, cached NLB images, or generated extension packages.

## Build environment

The release was prepared with:

- macOS on Apple silicon;
- Node.js 22.15.0;
- npm 11.6.0; and
- the dependency versions locked in `package-lock.json`.

All build and packaging tools are open-source npm packages. The build has no
private packages, private registries, web-based compilation steps, or required
environment variables. Mozilla's `web-ext` tool is pinned in the lockfile.

## Reproduce the submitted extension

From the source archive root, run:

```bash
npm ci
npm run package:firefox
```

The command typechecks the TypeScript, builds the React content script with
Vite, copies the licence and notices, runs Mozilla's add-on linter, verifies
that only the three reviewed warnings described below remain, and creates:

```text
nlb-seat-helper-firefox.zip
```

The package root contains `manifest.json`, `content.js`, `content.css`, the
extension icons, `LICENSE.txt`, `NOTICE.txt`, and `THIRD_PARTY_NOTICES.txt`.
ZIP container metadata such as timestamps can differ between rebuilds; compare
the extracted files. The generated extension files are deterministic with the
locked dependencies.

## Third-party libraries

Runtime code includes the official npm releases of React 18.3.1 and React DOM
18.3.1. Build-time dependencies and their exact resolved versions and official
npm package sources are recorded in `package.json` and `package-lock.json`.
No third-party library has been modified or loaded remotely at runtime.

`npm audit --omit=dev` reports zero runtime vulnerabilities. A full development
audit currently reports `image-size` through Mozilla's `addons-linter` and
`web-ext`; the published extension does not contain those build tools or parse
untrusted images through them. npm's proposed remediation is a downgrade from
the pinned current `web-ext` release, so it is not applied.

## Reviewed linter warnings

Two `UNSAFE_VAR_ASSIGNMENT` warnings in `content.js` are generated by React
DOM's production implementation. Project source contains no `innerHTML` or
`dangerouslySetInnerHTML`. One
`KEY_FIREFOX_ANDROID_UNSUPPORTED_BY_MIN_VERSION` warning is caused by the
Firefox 140 minimum and built-in data-consent key; this submission targets
Firefox Desktop only. `scripts/lint-firefox.mjs` checks the exact codes, files,
and counts and fails for any new error, notice, or warning.
